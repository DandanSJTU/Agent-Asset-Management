# 在线链路工程手册

> 面向工程侧的首页信息流在线链路说明：环节职责、工程规格、配置入口。
> 口径与业务结论见 [[推荐指标口径速查]]，策略台账见 [[内容治理策略台账]]。

## 一、全链路
```
内容池/投放池 → 召回（多通道并行，候选千级）
   → 粗排（轻量打分，截断百级）
   → 精排（多目标大模型打分）
   → 重排（打散 / 多样性 / decay）
   → 展示
退场 Drop：横切召回（候选截断）、粗排（融合打分）、精排（show/click 特征）
```

## 二、各环节工程规格
| 环节 | 工程入口 | 关键配置/规格 |
|---|---|---|
| 召回 | 多通道并行 + 城市/BU 配额 + 混排分 + 退场截断 | 配额 普通 2:5:5:4 / 一般意图 3:6:6:5 / top3 意图 4:10:6:5 |
| 粗排 | 三塔 + SENet，负采样 0.75 次方，蒸馏对齐精排 | 粗排后融合退场分（AB id=2598，B/E 版无显著差异） |
| 精排 | base_v9_4.yaml（elf-plugin-feeds），zeus 调度 | dense 冷启 seed=42，参数量约 187.7 万 |
| 重排 | 城市打散（一城 ≤10）、时间 decay、标题/OCR simhash 打散、DPP | timeDecayWeight × score.prem 融合方式**待补文档** |
| 退场 | DropOperator.java → UserDropWeightService.java | 队列 城市级 top100 / 单品级 top5000，起始分 0.4，有效期 365 天 |

## 三、配置原则
- 所有阈值走 eagleconf，禁止硬编码；变更留痕 + 分钟级回滚。
- 变更单需含：当前值→目标值、影响面、回滚值、灰度计划、观察指标、回滚触发、对照基线快照。
- 高风险配置（退场参数、配额比例、decay 权重、base_ratio、冷启 seed）需双人确认。

## 四、已知文档缺口
1. 退场分 sigmoid 降权映射完整公式（源文档为图片）。
2. 重排 timeDecayWeight 与精排分融合方式。
3. DPP kernel matrix 融合公式与相关性/多样性权重取值。
4. 「点击抬升 Y/N」的具体抬升逻辑。
