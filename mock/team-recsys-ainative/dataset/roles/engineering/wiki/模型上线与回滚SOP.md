# 模型上线与回滚 SOP

> 目标：让发布从「重大事件、层层签字」变成「日常动作、可随时回滚」。
> 一致性核查清单见算法侧 [[离线在线一致性核查清单]]。

## 一、上线前四件事
1. **离线指标达标**：GAUC / NDCG 等离线指标按实验设计达标。
2. **一致性通过**：离线在线一致性（重合度 / hit ratio）核查通过。
3. **开关与回滚值已配**：eagleconf 配置项、回滚值、灰度比例就位。
4. **监控与告警已挂**：核心指标与护栏指标的告警阈值就位。

> 教训：粗排三塔模型（AB id=3393）模型 auc 比基线高 2pt+，但融合后 gauc 反降 1pt —— 模型变强不等于上线有效，一致性必须前置核查。

## 二、灰度顺序
```
单场景（如行前 C 站，小流量）
  → 扩量（同场景更大流量 / 相邻场景）
  → 全量
每步设观察窗口（建议 ≥7 天，覆盖周内/周末差异）
```

## 三、回滚触发（到线即回滚）
- 核心点击指标（pv_ctr / uv_ctr，标明口径）显著负向
- 留存指标（APP 首页 UV / 复访率）显著负向
- Evals 回归失败
- 告警连续触发且无明确归因

回滚走配置，分钟级生效；回滚后 24h 内出初判报告。

## 四、基础设施变更
- 训练平台迁移（异步 → 同步、迁 GPU）：需重跑一次全流程演练再切正式任务。
- 同步框架调参：完成标准需在迁移前定义（当前未定义）。
- 大模型配套：词表已导 redis（MOKA/BCE）与 cv；Fealib op 支持 redis 索引词表仍 DOING，是 LLM-emb 特征上线阻塞项。
