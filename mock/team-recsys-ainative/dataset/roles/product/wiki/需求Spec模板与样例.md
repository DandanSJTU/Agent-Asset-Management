# 需求 Spec 模板与样例（1-2 Page Spec）

> 团队约定：策略类需求一律用 1-2 Page Spec，替代 15-30 页 PRD；用可点击原型替代需求评审会。
> 适用范围：首页信息流（T 站 + C 站）召回 / 粗排 / 精排 / 重排 / 退场 / 内容池相关需求。

## 一、模板（四段式）

### 1. 背景（问题 + 证据）
- 一句话问题：谁在什么场景下遇到什么问题。
- 证据：指标 / case，必须带口径（pv/uv）、来源（大报表/AB）、底表、实验号。
- 无数据支撑的部分显式标注「假设」，并给出验证假设的最小实验。

### 2. 方案（含影响面与回滚）
- 改动落到漏斗哪一环。
- 分平台分场景影响：T 站 / C 站 × 行前 / 行中，逐项说明预期方向。
- 配置开关与回滚方式（eagleconf、灰度比例、回滚触发条件）。

### 3. 指标（主指标 + 护栏指标）
- 主指标：pv_ctr 或 uv_ctr（标明口径）+ 预期幅度 + 观察周期。
- 护栏：留存（APP 首页 UV / 复访率）、时长、一个月新鲜度、top100 集中度。
- **无护栏的实验不允许开**。

### 4. 验收（通过线 + Evals）
- 通过线写成可判定的数值条件。
- Evals 集：需新增或回归的评测集。
- 决策人：谁拍板推全 / 回滚。

## 二、样例：站外趋势热点分发 V1（已定稿）

**背景**：首页信息流在部分城市供给不足、同质化明显；站外已热内容（竞品 / 旅游局 / 公众号 / 全网热门）未被利用。证据：城市内容供给表显示长尾城市 3 月新增内容数偏低（待补充具体数值，假设级证据）。

**方案**：LLM 检索站外热点信号 → 热度分公式打分 → 注入首页信息流候选池（供给侧增量，不替换存量）。落点：召回层新增信号源 + 混排分加权。

**指标**：主指标 pv_ctr（AB 口径，cid 去重）；护栏为复访率、一个月新鲜度、top100 集中度。

**验收**：待算法出基线对照方案后开 AB；未排期前状态为「pending」，owner 林夏，deadline 2026-10-31。

## 三、常见退返原因
1. 只给汇总口径，没拆 T 站 / C 站、行前 / 行中。
2. 只列主指标，没有护栏指标与通过线。
3. 把假设写成已验证结论。
4. 没写配置开关与回滚方式。
