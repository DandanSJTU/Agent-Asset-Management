# 精排模型演进与实验台账

> 精排是漏斗最核心的打分层：对粗排截断后的候选（百级）用大模型预估多目标分（点击、时长等），输出相关性排序交重排打散。
> 基线：base_v9_4（elf-plugin-feeds，zeus 调度），行前 / 行中两套场景。

## 一、演进主线
| 阶段 | 代表 | 要点 |
|---|---|---|
| TS 精排 | TS 一期 / 二期（去 uid cid）/ 三期（行为序列升级） | 早期精排主力 |
| 多目标多场景 | MMoE / PPNet 门控 | MMoE 有收益；PPNet train auc 正、eval auc 负（过拟合迹象） |
| debias | 位置 / 曝光偏差纠偏 | 纠偏曝光偏差 |
| 时长建模 | 时长 label 优化 | 点击外引入时长目标 |
| 大模型 | LLM-emb / Double Attention / 超长序列 / 生成式 | 减少 ID 依赖、引入内容信号 |

## 二、2023H2 全年收益（行前 + 行中长期对照）
| 场景 | 人均点击 pv | 点击 uv | 人均列表内容时长 | 曝光渗透 |
|---|---|---|---|---|
| 行前 | +4.54% | +3.10% | +3.45% | +0.70% |
| 行中 | +10.75% | +7.51% | +4.11% | +1.01% |
| 汇总（曝光 pv 口径） | **+5.83%** | **+4.02%** | **+3.59%** | **+0.76%** |

> 行前下半年上线 6 版模型（309/316/90/335/376/315），制定「2 期大对照」长期实验衡量累积收益。

## 三、关键实验结论
| 实验 | 结论 | 状态 |
|---|---|---|
| MMoE 多场景门控 | 有收益 | 采用 |
| PPNet | train auc 正 / eval auc 负（过拟合） | 未采用 |
| PCGrad 多目标梯度调和 | 点击 GAUC -5.8~6.9 万分位、时长 ndcg -1.2~1.6 万分位、导流 +1.3~1.9 千/百分位 | 未推全 |
| 粗排三塔（AB id=3393） | 模型 auc +2pt，融合后 gauc -1pt；pv ctr -0.08%、时长 +0.3%、新鲜度 -0.56% | 融合环节待查 |
| dense 冷启 seed=42 | 锁 seed 后两遍训练差异稳定（参数量约 187.7 万） | 采用 |

## 四、大模型与生成式（2026 方向）
- side-information 入图节点（EGES / GCN / GraphSage）
- LLM-emb：聚类/标签 T2I、self-attention、长序列建模（GSU+ESU、ETA+simhash 优化 SIM）、DIN 系 target-attention
- 工程配套：词表已导 redis（MOKA/BCE）与 cv；Fealib op 支持 redis 索引词表 DOING
- 生成式：tokenizer、OpenOneRec 落地、生成式召回 serving；Scaling up（hyperrec_918 / hyperrec_858_rankmixer_max_seq）
- 状态：调研中，未上线
