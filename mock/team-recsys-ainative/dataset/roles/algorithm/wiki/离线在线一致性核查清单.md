# 离线在线一致性核查清单

> 用途：模型/特征/配置上线前的最后一道闸。离线涨、线上不涨的绝大多数问题出在这里。
> 教训来源：粗排三塔（AB id=3393）——模型 auc 比基线高 2pt+，融合后 gauc_scoreRough 反降约 1pt。

## 一、特征一致性
- [ ] 特征覆盖度：线上特征缺失率是否高于离线训练样本？
- [ ] 特征分布：线上实时特征与离线特征的分布漂移（均值/分位数）在阈值内？
- [ ] 特征口径：线上 feature lib 与离线样本生成的算子、版本号一致？
- [ ] 时间窗口：5min/60min/1day/7day/15day 窗口的边界定义一致？

## 二、模型一致性
- [ ] 模型版本：上线版本号与离线评估版本号一致？
- [ ] 冷启配置：dense 冷启 seed 是否锁定（当前 42）？
- [ ] 训练稳定性：连续两遍训练的指标差异在可接受范围？
- [ ] 融合环节：融合后的排序指标（gauc）是否仍优于基线？**不只验模型自身**

## 三、链路一致性
- [ ] 与下游重合度 / hit ratio：粗排 topN 与精排 topM 的重合度是否异常下降？
- [ ] 候选量：召回候选量、退场截断数是否与离线假设一致？
- [ ] 配额与混排：城市/BU 配额、explore 加权是否同期变更？
- [ ] 重排：打散 / decay / DPP 是否改变了精排分的生效顺序？

## 四、指标一致性
- [ ] 口径：pv_ctr 还是 uv_ctr？大报表（vid）还是 AB（cid）？
- [ ] 底表与实验号：是否标注？
- [ ] 分层：行前/行中、T/C、新老用户、质量分桶（0-10 vs 10-100）是否分别看？
- [ ] 周期：观察窗口 ≥7 天，覆盖周内/周末差异？

## 五、判定
| 情况 | 处理 |
|---|---|
| 四项全通过 | 可进入灰度 |
| 特征一致性不通过 | 驳回，先修特征口径 |
| 融合环节指标反降 | 驳回，重做融合方案（三塔案例） |
| 指标口径缺失 | 结论不可用，补数据重跑 |
