# 首页信息流策略地图（团队共享入口）

> 本页是团队 Wiki 的主入口，串起首页信息流推荐的完整链路。
> 业务域：携程 Trip 首页信息流（T 站 + C 站双平台），行前 / 行中 / 目的地多场景。

## 一、全链路
```
内容池/投放池 → 召回（多通道并行，候选千级）
   → 粗排（轻量打分，截断百级）
   → 精排（多目标大模型打分）
   → 重排（打散 / 多样性 / decay）
   → 展示
退场 Drop：横切召回（候选截断）、粗排（融合打分）、精排（show/click 特征）
```

## 二、五环节速查
| 环节 | 一句话定位 | 核心机制 | 责任角色 | 详情 |
|---|---|---|---|---|
| 召回 | 多通道并行产出候选 | 20+ 通道代号（CTP/ISA/IHC/SWI/STS/QR/NUC…）、城市/BU 配额、混排分 | 算法 + 工程 | [[召回通道字典]] |
| 粗排 | 轻量截断，对齐精排 | 三塔 + SENet，负采样 0.75 次方，蒸馏对齐精排 | 算法 | [[精排模型演进与实验台账]] |
| 精排 | 核心打分层 | base_v9_4、MMoE 多目标多场景、大模型/生成式方向 | 算法 | [[精排模型演进与实验台账]] |
| 重排 | 多样性与体验 | 城市打散（一城 ≤10）、时间 decay、OCR/标题 simhash 打散、DPP | 算法 + 工程 | [[在线链路工程手册]] |
| 退场 | 降权过度曝光（横切） | 增量退场分，城市级 / 单品级，作用于召回 + 粗排 + 精排 | 工程 + 算法 | [[退场机制配置台账]] |

## 三、贯穿全链路的关键概念
- **场景**：行前 / 行中 / 目的地 / 沉浸式视频流 / IBU 信息流，多数环节分行前 / 行中两套。
- **用户分层**：HASORDER / NOORDER_HASINTENT / NOORDER_NOINTENT，召回与退场都按此分层。
- **核心指标**：点击 pv/uv、人均时长、新鲜度、集中度（top100），多数实验是「点击 vs 多样性/新鲜度」的 tradeoff。
- **实验线**：eagl3（召回 U2I）、xxlhp、drop（退场）、220520_BBZ_paixu（排序）、6601（重排）、3393（粗排）、2598（退场粗排融合）。
