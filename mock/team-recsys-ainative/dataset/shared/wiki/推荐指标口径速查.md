# 推荐指标口径速查（团队共享）

> 目的：让实验结论、周报、OKR 之间用同一套口径对话。
> 只沉淀定义，业务结论以各实验源文档为准；具体取数以线上底表 / 报表为准。

## 一、ctr：pv_ctr vs uv_ctr（最易混）
| 原子量 | 含义 | 口径 |
|---|---|---|
| 曝光 pv | 曝光次数 | 卡片是否全部露出为一次曝光 |
| 点击 pv | 点击次数 | — |
| 曝光 uv | 曝光人数 | `count(distinct cid)` |
| 点击 uv | 点击人数 | `count(distinct cid)` |

| 指标 | 公式 | 含义 |
|---|---|---|
| pv_ctr | 点击 pv / 曝光 pv | 每次曝光的点击效率 |
| uv_ctr | 点击 uv / 曝光 uv | 多大比例的曝光用户产生点击 |

⚠️「点击 uv / 点击 pv」是原子计数，「uv 点击率 / pv 点击率」是比率，不是同一层级。

## 二、渗透率（OKR 核心指标）
```
渗透率 = 首页信息流整体有效曝光量(expo_uv) / APP首页UV(home_uv)   -- 均按 cid 去重
分子 expo_uv = count(distinct case when expo_label=1 then clientcode end)
  底表 dw_mobdb.edw_trace_home_strmg_expo
  过滤 blocktitle in ('当季热门','当地热门')；lower(biztype) not in ('sdk','2nd')；
       nvl(index,'') <> ''；abnormallabel <> 'abnormal'
分母 home_uv = count(distinct clientcode)
  底表 sharein_ctrip.edw_ubt_pageview_day
  过滤 context.page='home' and agent.platform in ('12','32','43')
```
⚠️ 新老指标陷阱：新指标 `信息流监控_信息流曝光率_new`（2022 年后）；旧指标 `渗透率_total_algorithm_home-行前_total_total` 已废弃不准。

## 三、大报表 vs AB 指标（同名不同算）
| 维度 | 大报表 | AB 指标 |
|---|---|---|
| uv 去重键 | vid | cid |
| 与 pageview 关联 | 关联，关联不上的舍弃 | 不关联，直接取曝光点击 |

→ 两套体系绝对值不可直接对比，只能各自看趋势。
AB 底表：曝光 `dw_mobdb.edw_trace_home_strmg_expo`、点击 `dw_mobdb.edw_action_home_strmg_click`（actioncode='c_newflow_click'）、首页 uv `sharein_ctrip.edw_ubt_pageview_day`；行前行中取 `edw_odp_ubd_home_rec_expo_click_detail_bysid.travel_status`。

## 四、其他常用指标
| 类别 | 指标 | 口径 |
|---|---|---|
| 收益 | 信息流订单量 | 点击后 24h/7天 同 pid 订单（酒店/玩乐/门票/景酒） |
| 收益 | 信息流点击转化率 | 订单量 / 信息流点击 uv |
| 流量 | 信息流曝光率 | 信息流曝光 uv / app 曝光 uv |
| 流量 | 曝光产品占比（多样性） | `count(distinct pid)/count(distinct all pid)`，1日/7日 |
| 粘性 | 当日 APP/信息流回访 | `count(distinct 回访cid)/count(distinct cid)`，次日/7天/30天 |
| 粘性 | 平均停留时长 | session 内 `sum(曝光-点击)/uv`，首次曝光到首次点击 |
| 粘性 | 平均浏览深度 | Σ session 访问深度 / Σ session 条数 |

## 五、用户分层口径
**按内容消费生命周期**（Trip，分母 = DAU）：全站无行为新用户 29.8%、信息流无行为新用户 18.7%、老用户 51.5%；uvctr 依次 19.3% / 22.0% / 34.4%。

**按旅行阶段**（强意图城市 + 待出行订单判定）：种草期 40.0%、预订期 35.6%、订后行前 38.5%、行中 23.8%、行后 8.4%（占比之和 >100% 因可多命中）。

## 六、引用规则（团队硬约束）
任何指标引用必须三件套：① pv/uv 口径；② 大报表还是 AB；③ 底表 + 实验号。缺一不可用。
