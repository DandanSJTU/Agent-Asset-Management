团队资产

成功提效经验怎么变成团队资产？

复盘写了没人翻，经验留在谁的脑子里？AI 根本调用不到——因为它们压根不在 AI 能触达的地方。

稳定性

同一 prompt，昨天惊艳今天翻车

质量全看"这次它恰好记住了没有"，时好时坏，无法预期。

它们，其实是同一个根因。
根因

那些能让 Agent 少走弯路的信息，从来没有被当成资产

核心判断
记忆不只"记住对话"，
凡是能让 Agent 少走弯路的信息，
都应被保存、组织并复用。
怎么提升

给每次 Loop 加一条经验值

每跑完一圈闭环，团队记忆库就 沉淀 1 条可复用经验 —— Agent 每次开工都站在上一次的成果上，越用越聪明。

技术方案

让经验保存、提炼、流动，然后注入工作流

对话逐层长成 L0–L3 分层记忆，跑通的任务练成 Skill，文档织成 Wiki——统一登记为记忆资产；Memory Hub 按 Binding · ACL · Version 治理，按身份装配给每个 Agent。
